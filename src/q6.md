> **Prompt.** \$400,000 mortgage, 30 years, 3% APR compounded monthly. Monthly payment?

## Intuition

A mortgage **is** an annuity — a level payment that exactly retires a known loan over a known horizon. Excel's `PMT` does this in one cell.

The gotcha: rate and period count must be on the **same clock**. APR ÷ 12 for the rate, years × 12 for the periods. Mix annual rate with monthly periods and you'll get a payment off by a factor of 12.

## Step by step

const mRate = apr / 12;

const totalInterest = totalPaid - loan;

## Amortization — watch the interest:principal mix flip over time

```js
function amortChart() {
  let bal = loan;
  const rows = [];
  for (let i = 1; i <= N; i++) {
    const interest = bal * mRate;
    const principal = payment - interest;
    rows.push({month: i, interest, principal, bal: bal - principal});
    bal -= principal;
  }
  const yearly = d3.range(1, yrs + 1).map(yr => {
    const slice = rows.slice((yr - 1) * 12, yr * 12);
    return {
      year: yr,
      interest: d3.sum(slice, d => d.interest),
      principal: d3.sum(slice, d => d.principal)
    };
  });

  const w = 780, h = 260, mar = {top: 20, right: 30, bottom: 40, left: 70};
  const svg = d3.create("svg").attr("viewBox", `0 0 ${w} ${h}`).attr("style", "max-width:100%;height:auto;");

  const x = d3.scaleBand().domain(yearly.map(d => d.year)).range([mar.left, w - mar.right]).padding(0.1);
  const maxBar = d3.max(yearly, d => d.interest + d.principal);
  const y = d3.scaleLinear().domain([0, maxBar]).range([h - mar.bottom, mar.top]);

  yearly.forEach(d => {
    svg.append("rect")
      .attr("x", x(d.year)).attr("y", y(d.principal + d.interest))
      .attr("width", x.bandwidth()).attr("height", y(0) - y(d.interest))
      .attr("fill", "#C00000").attr("opacity", 0.75);
    svg.append("rect")
      .attr("x", x(d.year)).attr("y", y(d.principal))
      .attr("width", x.bandwidth()).attr("height", y(0) - y(d.principal))
      .attr("fill", "#2E75B6");
  });

  svg.append("g")
    .attr("transform", `translate(0,${h - mar.bottom})`)
    .call(d3.axisBottom(x).tickValues(x.domain().filter(d => d % 5 === 0 || d === 1 || d === yrs)));
  svg.append("g")
    .attr("transform", `translate(${mar.left},0)`)
    .call(d3.axisLeft(y).tickFormat(d => "$" + d3.format(",.0f")(d)));

  // Legend
  svg.append("rect").attr("x", w - 200).attr("y", 10).attr("width", 12).attr("height", 12).attr("fill", "#2E75B6");
  svg.append("text").attr("x", w - 184).attr("y", 21).attr("font-size", 12).text("principal");
  svg.append("rect").attr("x", w - 100).attr("y", 10).attr("width", 12).attr("height", 12).attr("fill", "#C00000").attr("opacity", 0.75);
  svg.append("text").attr("x", w - 84).attr("y", 21).attr("font-size", 12).text("interest");

  svg.append("text").attr("x", mar.left + (w - mar.left - mar.right)/2).attr("y", h - 6)
    .attr("text-anchor", "middle").attr("font-size", 12).text("year of loan");

  return svg.node();
}
```

```js
amortChart()
```
