> **Prompt.** \$30 annual coupon for 4 years, plus \$1,000 face at end of year 4. Interest rate: 6% APR compounded **monthly**. What's the bond worth today?

## Intuition — the EAR trick

**The mismatch.** The coupons arrive **annually** but the rate compounds **monthly**. You can't just discount at 6%.

The fix: convert the APR to its **Effective Annual Rate** — the annual rate that already accounts for monthly compounding.

<div style="font-family:'Times New Roman',serif;font-size:20px;text-align:center;margin:14px 0;padding:14px;background:#F8F9FA;border-radius:4px;">
  <em>EAR</em> = (1 + <em>APR</em> / <em>m</em>)<sup><em>m</em></sup> &minus; 1
</div>

Then discount the annual cash flows at EAR. Skip this step and your bond is priced a few dollars too high — partial credit, not full credit.

## The killer chart — watch EAR diverge from APR as m grows

<div style="background:#FFF2CC;border-left:4px solid #BF9000;padding:10px 14px;border-radius:4px;font-size:14px;margin:14px 0;">
Drag the <strong>m</strong> slider. At m=1 (annual compounding) EAR = APR. As m climbs, EAR drifts upward — by m=365 (daily) the gap is sizable. The curve approaches a ceiling at <em>e</em><sup>APR</sup> &minus; 1 (continuous compounding).
</div>

```js
function earCurve() {
  const ms = d3.range(1, 366);
  const data = ms.map(mi => ({m: mi, ear: Math.pow(1 + apr/mi, mi) - 1}));
  const w = 760, h = 240, mar = {top: 20, right: 80, bottom: 40, left: 60};
  const innerW = w - mar.left - mar.right;
  const innerH = h - mar.top - mar.bottom;
  const svg = d3.create("svg").attr("viewBox", `0 0 ${w} ${h}`).attr("style", "max-width:100%;height:auto;");
  const x = d3.scaleLog().domain([1, 365]).range([mar.left, w - mar.right]);
  const earMax = Math.pow(1 + apr/365, 365) - 1;
  const y = d3.scaleLinear().domain([apr * 0.99, earMax * 1.02]).range([h - mar.bottom, mar.top]);

  // axes
  svg.append("g")
    .attr("transform", `translate(0,${h - mar.bottom})`)
    .call(d3.axisBottom(x).tickValues([1, 2, 4, 12, 52, 365]).tickFormat(d3.format("d")));
  svg.append("g")
    .attr("transform", `translate(${mar.left},0)`)
    .call(d3.axisLeft(y).tickFormat(d => (d*100).toFixed(2) + "%"));

  // APR baseline
  svg.append("line")
    .attr("x1", x(1)).attr("x2", x(365))
    .attr("y1", y(apr)).attr("y2", y(apr))
    .attr("stroke", "#999").attr("stroke-dasharray", "4 3");
  svg.append("text").attr("x", x(365)).attr("y", y(apr) - 6).attr("text-anchor", "end")
    .attr("font-size", 11).attr("fill", "#666").text(`APR = ${(apr*100).toFixed(2)}%`);

  // continuous-compounding ceiling
  const eCeil = Math.exp(apr) - 1;
  svg.append("line")
    .attr("x1", x(1)).attr("x2", x(365))
    .attr("y1", y(eCeil)).attr("y2", y(eCeil))
    .attr("stroke", "#7030A0").attr("stroke-dasharray", "2 4");
  svg.append("text").attr("x", x(365)).attr("y", y(eCeil) - 4).attr("text-anchor", "end")
    .attr("font-size", 11).attr("fill", "#7030A0").text(`continuous = ${(eCeil*100).toFixed(3)}%`);

  // EAR curve
  const line = d3.line().x(d => x(d.m)).y(d => y(d.ear));
  svg.append("path").datum(data)
    .attr("d", line)
    .attr("fill", "none").attr("stroke", "#2E75B6").attr("stroke-width", 2.5);

  // current m marker
  const cur = data.find(d => d.m === m) || data[data.length - 1];
  svg.append("circle").attr("cx", x(cur.m)).attr("cy", y(cur.ear)).attr("r", 6).attr("fill", "#C00000");
  svg.append("text")
    .attr("x", x(cur.m) + 10).attr("y", y(cur.ear) - 6)
    .attr("font-size", 13).attr("font-weight", 700).attr("fill", "#C00000")
    .text(`m=${cur.m},  EAR=${(cur.ear*100).toFixed(4)}%`);

  // axis labels
  svg.append("text").attr("x", mar.left + innerW/2).attr("y", h - 6).attr("text-anchor", "middle").attr("font-size", 12).text("compounding periods per year (log scale)");
  svg.append("text").attr("transform", `translate(15,${mar.top + innerH/2}) rotate(-90)`).attr("text-anchor", "middle").attr("font-size", 12).text("EAR");
  return svg.node();
}
```

```js
earCurve()
```
